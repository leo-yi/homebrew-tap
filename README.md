# Leo-yi Tap

## How do I install these formulae?

`brew install leo-yi/tap/<formula>`

Or `brew tap leo-yi/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "leo-yi/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
